# Meeting notes

1. Read the notes/transcript (a file, or pasted text; for audio use the `video` tool's audio extract first if a transcription tool is available).
2. Produce: **Summary** (3–5 lines), **Decisions** (what was decided, by whom), **Action items** (owner — task — due date; mark unclear owners/dates "unassigned"/"?" instead of inventing them), **Open questions**, **Next meeting**.
3. Keep names and numbers exactly as stated. Do not add opinions. Offer to write it to a file (Markdown or a Word document) or draft the follow-up email.
