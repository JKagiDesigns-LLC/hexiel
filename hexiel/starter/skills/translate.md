# Translate

1. Confirm the source and target language and the register (formal/informal; region such as pt-BR vs pt-PT).
2. Translate meaning, not word order. Keep names, product terms, numbers, dates, code and placeholders (`{name}`, `%s`) untouched; convert units and date formats only when asked.
3. For a file, keep its structure (Markdown headings, list items, table cells, JSON keys unchanged — translate values only) and write the result to a new file with the language code in its name.
4. List any phrases that are ambiguous or culturally specific with the choice you made, so a native reader can check them.
