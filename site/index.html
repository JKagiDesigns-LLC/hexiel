Stop renting your coding agent.

AI coding tools are amazing — and most of them are a monthly bill wired to someone else's servers. hexiel gives you the same kind of agent, but you own it, you choose the model, and it's designed to be fast on the computer you already have.

⌂ Local-first

Runs on Ollama, vLLM or LM Studio on your own machine or home server. Your code never has to leave your network. Prefer a frontier model for a hard problem? Switch to Claude, GPT, Gemini or OpenRouter in one command.

⚡ Fast on modest hardware

Anything that doesn't need a model — searching, mapping the project, waiting on tests, parsing logs — runs locally in Python. A lean prompt halved the time to process each request on an Intel iGPU mini-PC (46.5 s → 23.7 s).

♥ Free, and staying that way

Open source under GPLv3 with the Commons Clause. Use it, change it, share it, contribute back — free. It just can't be repackaged and sold without permission, so no one can turn it into the subscription it was built to replace.

Two interfaces, one agent

A fast full-screen terminal UI and a browser UI share the same brain — plus one-shot headless runs for scripts and an OpenAI-compatible API, so tools like OpenWebUI can talk to it.

  • Type / for a command menu with descriptions
  • A live activity line shows what it's doing, how long, how many tokens
  • Edits and commands ask first — or go hands-free with /auto

Remembers, plans and picks up where it left off

Reads your project's AGENTS.md / CLAUDE.md, keeps file-based memory, and tracks multi-step work in a todo.md that it maintains automatically — so if your laptop dies mid-task, hexiel -c resumes from an accurate checkpoint.

  • Auto-compaction at a Claude-Code-sized context window
  • Durable facts are saved to memory automatically
  • Each project keeps its own history and state

You're in control of every setting

Open /config (or ⚙ Settings in the browser), click a value, pick from the real options — including the models your server actually has — and choose this session or save permanently.

  • Edits one line of your config and keeps your comments
  • Updates itself with /update and resumes your conversation

What's actually different about hexiel

Engineered for the computer you have

Measured on an Intel iGPU mini-PC, not a datacenter. Searching, mapping, waiting on tests and parsing run in Python; a python tool batches many steps into one local script; the prompt is kept lean. Thinking can be switched off per model for speed.

Upkeep it does for you

Multi-step requests become tracked tasks with a checkpoint refreshed after every step, and durable facts are saved to memory during compaction — in Python, at zero token cost.

Fits into OpenWebUI

Serve hexiel as an OpenAI-compatible model that OpenWebUI (or any OpenAI client) can connect to, and run existing OpenWebUI tool, pipe and filter plugins inside hexiel without porting them.

Fixes and ships through merge requests

Crashes are recorded as incidents; /heal reproduces, fixes, tests and proposes a merge request, and /ship turns your work into one. Nothing merges without a human.

Which one is right for you?

If you live on Claude models and want deep IDE and desktop integration, Claude Code is superb. If you need MCP servers today or a permissive MIT license, opencode is a great choice. If you want a lightweight git-centric pair programmer, Aider is proven. If you want an agent that is free, runs well on modest local hardware, maintains its own memory and todo, and plugs into OpenWebUI — that's what we built hexiel for.

Try it in two minutes

You need Python 3.11+ and a model: Ollama for local, or an API key for a cloud provider.

git clone https://gitlab.com/jkagidesigns1/public/applications/hexiel.git
cd hexiel
python3 -m venv .venv
.venv/bin/pip install -e '.[serve]'
ln -s "$PWD/.venv/bin/hexiel" ~/.local/bin/hexiel

ollama pull qwen3.6:35b-a3b-coding    # or use a cloud key
cd ~/your-project && hexiel

Questions

Is hexiel really free?

Yes. The tool costs nothing and has no subscription. If you use a cloud model you pay that provider for what you use; local models are free.

Can it run completely offline / locally?

Yes — point it at Ollama or any OpenAI-compatible server on your machine or LAN. Web search obviously needs the internet, but everything else works locally.

What hardware do I need for local models?

Our test machine — an Intel mini-PC with integrated graphics — runs a 35B mixture-of-experts coding model at about 12 tokens/second. That model needs roughly 25 GB of memory, so plan for 32 GB of RAM or more. Smaller machines can run smaller models, or use a cloud model.

Which local model should I use?

Mixture-of-experts models with ~3B active parameters that support tool calling and vision — qwen3.6:35b-a3b-coding passed all our checks. Set reasoning_effort = "none" on slow hardware so it doesn't spend minutes "thinking".

Will my existing Claude Code skills work?

Yes. hexiel reads ~/.claude/skills directly, plus OpenWebUI tool/pipe/filter plugins.

Is it safe to let an AI run commands?

By default every edit and command asks for your approval first. The browser UI is local-only unless you explicitly expose it, and it warns you loudly if you do.

How do I contribute?

Fork, branch, open a merge request — or let hexiel do it with /ship. Changes are reviewed and approved by the maintainers.
